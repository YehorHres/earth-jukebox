# PROMPT v8 — адаптація під галерею NASA Earth Information Center (після v7)

Джерело: https://svs.gsfc.nasa.gov/gallery/earth-information-center/ (25 позицій у розділах Beauty Pieces,
Dashboards, Videos, Media Resources, Daily Visualizations). Мета: будь-яке відео/фото з EIC, яке завантажить
користувач, звучить осмислено; документальні ролики не «сонифікуються» вигаданим зв'язком.

## 0. Не зламати
Золотий тест v7 (5 треків галереї байт-в-байт) і всі попередні тести — зелені. Гілка `v8-eic`; у main лише
коли все зелене. Нові картки впливають лише на відео, що зіставились із карткою EIC.

## 1. Каталог EIC — `src/eic/catalog.json`
Для КОЖНОЇ з 9 Beauty Pieces (SVS id: 3912, 4950, 4993, 4960, 5011, 5313, 5196, 5425, 5533) відкрий сторінку
`https://svs.gsfc.nasa.gov/<id>/` (WebFetch) і заповни картку з фактів сторінки (нічого не вигадувати;
невідоме — null): id, назва uk/en, topic, motionType (temporal | rotating-globe | camera-pan-zoom | static |
chart | composite | 3d), змінна, одиниці, діапазон шкали, кольорова шкала (опис/опорні кольори, якщо є),
moreMeans (світліше/темніше/червоніше…), чи є colorbar/дата/текст на кадрі, регіон, роки, короткий опис для
незрячих (2–3 речення), автори/кредити, ключові слова для зіставлення (слова з назв файлів SVS).
Особливості: 4993 Dixie Fire — карта + графік площі (composite: карта → голос даних, графік → другий голос);
5313 Night Lights 2012–2023 — карта зміни + часовий ряд + вставки (composite); 4960 і 5533 — 3D/модель
(читати як temporal, без географічних підписів); 5011 блискавки — події-спалахи (кожен спалах → ерікон).
Для 6 Dashboards (40509, 40473, 40477, 40479, 40529, 40531) — картка-«родина» за темою дашборда
(topic, типові змінні) без деталей окремих візуалізацій.
Для Videos (40487, 40484, 14700, 14606, 14696, 14568, 14507, 14713) і B-roll 14371 — тип `documentary`.

## 2. Зіставлення завантаженого файлу з карткою
- Поле «Звідки відео?» (необов'язкове): вставити посилання SVS або вибрати зі списку EIC (з клавіатури).
- Автозіставлення за назвою файлу (ключові слова, SVS id у назві) → пропозиція «Схоже, це <назва>. Так/Ні».
- Картка задає тему, motionType, полярність, шкалу й опис (вступ і аудіолегенда беруть звідти).
- Для `documentary`: не сонифікувати як дані; повідомлення «Це документальне відео, а не карта даних —
  оберіть візуалізацію» (+ можливість усе одно увімкнути загальний режим, з попередженням).

## 3. Автоматичне розпізнавання документального відео (без картки)
Ознаки: часті склейки, обличчя/люди, природні кольори без шкали, мало статичних масок, текстові титри.
Висока впевненість → те саме повідомлення, що й для `documentary`.

## 4. Польові тести
Людина кладе у `samples/field-tests/` файли з EIC (бажано: 4950, 4993, 5011, 5313, 5196, 5425) і пише в NOTES.md.
Для кожного: зіставлення з карткою, motionType, полярність, рендер 20 с, кореляція голосу даних із головною
ознакою → `renders/field-report.json`. Ціль: правильна картка й тип руху для всіх; полярність збігається з NOTES.

Наприкінці: test.html (все + золотий) зелене → злий у main, тег safe-10, пуш main і тегів. README: розділ
«Підтримувані візуалізації EIC» (таблиця: id, назва, тип, як звучить). Звіт до 8 рядків.
