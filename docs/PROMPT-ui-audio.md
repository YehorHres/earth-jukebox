# PROMPT UI-audio — швидкість, мікшер, таймлайн (запускати ПІСЛЯ PROMPT-final і після злиття гілки друга ui-en)

Правила: гілка `ui-audio` від свіжого main; золотий тест і всі тести зелені; тексти — через систему перекладу
src/i18n (uk + en) і з підказками (data-tip), якщо вони вже є; не став питань; коміт → злиття → тег → пуш.

1. **Швидкість відтворення:** 0.5×, 0.75×, 1×, 1.25×, 1.5× (кнопки/селект + клавіші [ і ]). Відео
   (playbackRate) і музика синхронно: музика — зміною темпу планувальника, висота нот НЕ змінюється.
   Перемотка й зміна швидкості під час гри — без розсинхрону (перевірити тестом: розбіжність < 50 мс).
   Озвучення: «Швидкість 0,75».
2. **Мікшер:** для кожної партії — повзунок гучності (0–100 %) + наявні Вимк./Соло; окремо «Голос даних» і
   «Загальна гучність». Повзунки — `input type=range` з підписом і `aria-valuetext` («Бас, 70 %»), стрілки ±5 %.
   Налаштування мікшера зберігати в localStorage. Мікшер не змінює партитуру (золотий тест — зелений).
3. **Таймлайн:** перемотка кліком/перетягуванням і клавішами (←/→ ±5 с, Home/End); позначки розділів
   (вступ, наростання, кульмінація, розв'язка) і подій; `role="slider"` з `aria-valuetext`
   («1:20 з 2:40, кульмінація»); підказка при наведенні на позначку (що за подія).
4. Тести: синхрон при 0.5× і 1.5×; мікшер змінює лише гучність; таймлайн керується з клавіатури.
Звіт до 5 рядків.
