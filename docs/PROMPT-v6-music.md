# PROMPT v6 — повернути музику й контраст (ранок 15.11)

Відгук команди після етапів A/16/17 (ECCO2, нічні вогні, ураган): «усе однотипно; скрізь якась сирена/виття;
немає потужної мелодії; не чути, коли ураганів стає більше; нічні вогні раніше були "дзинь-дзелень",
тепер темне виття». Причини знайдено в коді — виправ їх. Принцип «тембр = тема, ноти = дані» лишається,
але МУЗИКА важливіша за дидактику: зв'язок із даними має бути чутним через музичні засоби.

Правила роботи: нова гілка `v6-music` від main; тести 15/A/16/17 мають лишитися зеленими (тести, що прямо
суперечать цьому ТЗ — оновити, з поясненням у коміті); не питай людину; наприкінці коміт, злиття в main,
тег `safe-7`, пуш main і тегів, звіт до 8 рядків. Відкат при провалі: тег `safe-5`.

## 1. Прибрати «сирену» (src/audio/synths-grammar.js, src/grammar.js, parts/grammar-parts.js)
- Голос даних грає СПРАВЖНІМ семплованим інструментом теми (з наявних семплів: piano, violin, flute,
  horn, trumpet, trombone, harp, xylophone, saxophone…), НЕ осциляторами. Запасний синтез — лише без семплів.
  Призначення: ocean-currents → violin (+ harp у супроводі), temperature → piano/violin, storms → horn/trombone,
  nightlights → xylophone/піано у високому регістрі (дзвінкі короткі ноти), co2 → horn/trumpet, ice → piano.
- ПРИБРАТИ гліссандо між нотами повністю.
- Голос даних лише на +3…+4 дБ над супроводом (не +8…14); прибрати глибокий EQ-виріз супроводу
  (максимум −3 дБ), прибрати −7 дБ для всього супроводу.
- Референсний тон — тільки 1–2 с на початку; дрон-орієнтир ВИМКНЕНО за замовчуванням (лишити опцію).
  Тіки шкали часу — вимкнено за замовчуванням.

## 2. Потужна мелодія з мотивом (замість «нота = значення кожного кроку»)
- Для кожної теми — запам'ятовуваний мотив 4–8 нот (свій ритм та інтервали), у ладі.
- Мелодія = мотив, що повторюється й розвивається (секвенції, варіації, відповідь «питання–відповідь»).
  Дані керують: ТРАНСПОЗИЦІЄЮ мотиву (значення ↑ → мотив вище), густотою ритму (зміни ↑ → дрібніші
  тривалості), гармонізацією (напруга ↑ → темніші акорди), подвоєнням октавою й інструментами в кульмінації.
- Правила сольфеджіо з етапу 16 (діатоніка, каденції, обмежені стрибки) зберегти.

## 3. Контраст — щоб «більше/менше» було очевидно на слух
- Динамічний діапазон: гучність треку нормалізуй ОДИН раз (інтегрально −16 LUFS), але всередині треку
  енергія даних керує гучністю в діапазоні ~12 дБ (тихі епізоди справді тихі, кульмінація — повна).
  Прибрати «±4 дБ вирівнювання» всередині треку.
- Кількість партій від даних: спокій 2–3 → пік 6–7 (бюджет 7). Регістр розширюється з енергією.
- Ударні від даних: спокій — тиша/щітки; ріст — половинний → звичайний → подвійний розмір (half-time →
  double-time), на піках — литаври/тарілки/брас-удари.
- storms: що більше активних зон/площі шторму — тим більше шарів ударних, брасу, вітру й швидший ритм.
- ocean-currents: тепле (частка гарячих зон ↑) → мажор, вищі й яскравіші інструменти; холодне → мінор,
  низькі струнні, low-pass; панорама — де тепло/холод у кадрі.
- Тест (audio-report): кореляція енергії даних з короткочасною гучністю (3 с) ρ ≥ 0.7 для кожного треку
  галереї; діапазон гучності (LRA) ≥ 8 LU; пік ≤ −1 dBFS; інтегрально −16 LUFS ±0.5.

## 4. Нічні вогні — повернути «дзинь-дзелень»
- Головна текстура — мерехтливі вогники: короткі дзвінкі ноти (xylophone/celesta/glockenspiel/піано вгорі)
  у пентатоніці ладу. Кількість нот за такт = кількість/частка вогнів (lightPoints, lightClusters) —
  більше вогнів → помітно густіший «дощ» нот; панорама кожної ноти — за горизонтальною позицією вогню/зони.
- Великі кластери (агломерації) → акорд-дзвін; нові вогні → нова нота (ерікон «іскра» можна злити з цим).
- Під цим — тихий теплий пед і м'який пульс (без виття). Темні ділянки — тиша, а не гул.
- Тест: кореляція кількості нот «вогників» на такт із lightPoints ρ ≥ 0.8.
