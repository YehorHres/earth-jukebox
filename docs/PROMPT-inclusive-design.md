# Інклюзивний дизайн інтерфейсу — бриф для окремої людини / сесії Claude

Мета: інтерфейс Earth Jukebox має бути зручним для НЕЗРЯЧИХ (скрінрідер NVDA/VoiceOver, тільки клавіатура)
і СЛАБОЗОРИХ (збільшення, високий контраст, великий текст), а також для всіх інших. Стандарт — WCAG 2.2 AA.

## Межі роботи (обов'язково)
- Працюй у гілці `design-a11y` (git checkout -b design-a11y). НЕ пуш у main — тільки свою гілку + Pull Request.
- Можна змінювати: `index.html`, `src/style.css`, `src/ui/*`, `src/a11y/*`, тексти в `samples/catalog.json`.
- НЕ чіпати: `src/audio/*`, `src/composer/*`, `src/mapping/*`, `src/analysis/*`, `src/features/*`,
  `src/grammar.js`, `src/topics/topics.json` (звук і аналіз — інша людина).
- Перед кожним комітом: `python tools/serve.py 8000` → http://localhost:8000/test.html — усе зелене,
  консоль без помилок; трек із галереї грає.
- Режим економії: читай CLAUDE.md і цей файл; не читай ideas-gemini.txt, *.analysis.json, vendor/; шукай через grep.

## Що зробити (за пріоритетом)
1. **Клавіатура:** кожна дія доступна з клавіатури; логічний порядок Tab; видимий фокус (обвідка ≥ 3 px,
   контраст ≥ 3:1); посилання «Перейти до плеєра» на початку; Esc закриває спливні елементи; без пасток фокусу.
2. **Скрінрідер:** `lang="uk"` (і `lang="en"` для англ. фрагментів); один `h1`, логічні заголовки;
   landmarks (`header`, `main`, `nav`, `aside`); у кожної кнопки зрозуміла назва (не «Вимк.», а «Вимкнути партію
   Бас»); `aria-pressed` для перемикачів (Соло/Вимк., UA/EN); прогрес аналізу — `role="progressbar"` або aria-live;
   не дублювати оголошення (aria-live лише для важливого, `polite`).
3. **Слабозорі:** контраст тексту ≥ 4.5:1 (великого ≥ 3:1) в обох темах; кнопка «Великий текст» (A+/A−,
   збереження в localStorage); режим «Високий контраст» + підтримка `prefers-contrast` і
   `forced-colors` (Windows High Contrast); при масштабі 200 % і ширині 320 px — без горизонтального скролу
   й без обрізаного тексту; цільові зони кнопок ≥ 44×44 px.
4. **Рух і сенсорика:** `prefers-reduced-motion` — без анімацій/миготіння; нічого не блимає > 3 разів/с;
   звук не стартує сам — лише після натискання «Грати».
5. **Зрозумілість:** простий текст (рівень «пояснити другові»); коротке «Як користуватися» (3–5 кроків)
   угорі, доступне скрінрідеру; список клавіш (кнопка «?» + озвучення); підписи полів і помилок текстом,
   не лише кольором; колір ніколи не єдиний носій інформації.
6. **Мобільні:** працює з TalkBack/VoiceOver; великі кнопки; режим «дотик до карти» з підказкою.

## Перевірка (опиши результат у PR)
- Пройти весь сценарій ЛИШЕ з клавіатури: вибрати відео → тема → Аудіолегенда → Грати → соло партії →
  «Дослідити карту» → Трек у WAV.
- Пройти той самий сценарій з NVDA (Windows, безкоштовно) із вимкненим монітором / закритими очима.
- Lighthouse (Chrome DevTools → Lighthouse → Accessibility) ≥ 95; axe DevTools — 0 критичних помилок.
- Масштаб 200 % і ширина 320 px; Windows High Contrast.
- У PR: що змінено, скріншоти до/після, оцінка Lighthouse, що не встигли.
