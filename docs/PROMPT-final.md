# PROMPT FINAL — універсальність без поломок (один запуск, обмежені ліміти)

Мета: будь-яке відео/фото з NASA EIC звучить осмислено; те, що вже працює (5 треків галереї), НЕ змінюється.
Деталі механізмів — у docs/PROMPT-v7-robust.md (§1–5) і docs/PROMPT-v8-eic.md (§1–3). Читай лише потрібний
параграф, коли до нього дійдеш.

## Правила (обов'язкові)
- Економія: не читай ideas-gemini.txt, *.analysis.json, vendor/; шукай через grep; без скріншотів;
  рендери короткі уривки; повний test.html — один раз наприкінці КОЖНОГО блоку. Не став питань.
- Робота блоками. Після кожного блоку: test.html зелений (усе + золотий тест) → коміт → злиття в main →
  тег `safe-10a`, `safe-10b`… → пуш main і тегів → 3 рядки в docs/FINAL-REPORT.md. Не зелене після 2 спроб →
  не зливати, записати в звіт, переходити до наступного блоку.
- Якщо відчуваєш, що ліміт закінчується, — спершу закоміть і злий те, що зелене, потім зупинись.
- Файли samples/field-tests/ і converted/ — не комітити.

## Блоки (у порядку пріоритету)
**A. Золотий тест (обов'язково першим, до будь-яких змін).** v7 §0: хеш партитур 5 треків галереї →
tests/golden-scores.json + тест. Злити одразу.

**B. Типи руху: rotating-globe + camera-pan-zoom** (v7 §1, перші два пункти) + вимкнути рух/обертання як
джерело гучності й подій для цих типів. Синтетичні тести на обидва.

**C. Шкала без легенди + перемикач полярності** (v7 §2–3): paletteValue для невідомих шкал (зелені, viridis);
перемикач «більше = світліше / темніше / червоніше» в UI з озвученням.

**D. Формати.** Якщо відео не декодується: зрозуміле повідомлення в застосунку (текст + aria-live):
«Браузер не може відтворити цей формат (ймовірно H.265/HEVC або дуже висока роздільність). Завантажте MP4 H.264
1080p зі сторінки NASA SVS або сконвертуйте файл». Великі файли: аналіз не більше ~400 кадрів, без збою пам'яті.

**E. Польові тести** на samples/field-tests/ (опис у NOTES.md). Кожен файл спершу спробуй відкрити як є і
запиши результат. Не відкрився — копія в H.264, 1280 px, перші 60 с у samples/field-tests/converted/
(ffmpeg, якщо є; інакше npx ffmpeg-static або pip imageio-ffmpeg, без глобальної установки) і тест копії.
Великі файли — перші 60 с. Для «?» у NOTES визнач полярність зі шкали на кадрі або сторінки SVS (WebFetch),
запиши джерело. Результат → renders/field-report.json і таблиця у FINAL-REPORT.md (файл, тип руху, шкала,
полярність, ρ голосу даних із головною ознакою, проблеми). Виправ ДРІБНІ проблеми, знайдені тут.

**F. Типи static, chart, composite** (v7 §1, решта пунктів). Composite: Dixie (карта + графік) і нічні вогні
5313 (серія + карта змін + вставки) — читати найбільшу панель, графік — другим голосом.

**G. Картки EIC — тільки для 8 відео з field-tests + ECCO2** (v8 §1, скорочено, без дашбордів і відеороликів)
і зіставлення файлу з карткою за назвою (v8 §2, без поля посилання).

**H. (лише якщо лишились ліміти)** v8 решта: дашборди, документальні відео, поле посилання SVS.
