# Нічна робота (15.11, без людини) — правила і черга етапів

Ти працюєш вночі сам. Людина спить і НЕ відповідатиме. Не став питань — вирішуй за правилами нижче.

## Правила
1. **Економія токенів:** читай CLAUDE.md і тільки потрібний розділ промпту; не читай ideas-gemini.txt,
   *.analysis.json, vendor/; шукай через grep; без скріншотів; тести один раз у кінці етапу; для звуку
   рендери один короткий трек (повний перерендер — тільки у фінальному етапі).
2. **Кожен етап:** нова гілка `night-<етап>` від main → робота → test.html.
   - Усі тести зелені (включно зі старими: 15, A, 16) → злий у main, постав тег `night-<етап>`.
   - Не вдалося після 2 спроб → закоміть як є в гілці, НЕ зливай, опиши проблему у звіті, переходь до
     наступного етапу (вони незалежні).
3. **НІКОЛИ не пуш** (ні main, ні гілки, ні теги). Нічого не видаляй. Не змінюй історію (без rebase/force).
4. **Не ламай зроблене:** бюджет партій ≤ 6, граматика звуку (Етап A), правила мелодії (Етап 16),
   мастеринг (−16 LUFS, пік ≤ −1 dBFS) — їхні тести мають лишатися зеленими.
5. **Неоднозначність** → обирай найпростіший варіант, що відповідає духу ТЗ, і запиши рішення у звіт.
6. **Звіт:** після КОЖНОГО етапу допиши в `docs/NIGHT-REPORT.md`: етап, гілка/тег, злито чи ні,
   тести (X/Y), що зроблено (≤ 5 рядків), що послухати вранці (який трек, на що звернути увагу),
   відомі проблеми. Комітни звіт разом з етапом.
