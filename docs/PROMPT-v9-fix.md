- Океан (5425): наближення до білої затоки, що займає весь екран, — голосно; видно всю планету — тихо.
- Пожежа (4993): незрозуміло, що міряємо — згоріле (сіре) чи те, що горить (жовте/червоне/помаранчеве).
Спільна причина: «скільки на екрані» плутається зі «скільки насправді»; рух камери/наближення/обертання і
форма треку (вступ/кульмінація/розв'язка) керують гучністю замість даних.

## Блок A — гучність = щільність даних, а не площа на екрані (найважливіше)
1. Головна «кількість» для гучності/напруги/густоти — ЧАСТКА даних на ВИДИМІЙ поверхні (піксели даних /
   піксели області даних: диск глобуса або карта в кадрі), а не частка всього кадру. Наближення камери,
   обертання й поява диска НЕ змінюють гучність самі по собі.
2. Для завантажених відео прибрати вплив рухових ознак (frameDiff, speed, activeMass кадру, площа диска) на
   гучність, напругу й кульмінацію. Форма треку (вступ/наростання/кульмінація/розв'язка) — лише з ряду
   «кількості» даних: кульмінація там, де даних найбільше; немає даних — немає штучної кульмінації. Вступ —
   максимум 2 такти тихіше, далі гучність лише від даних.
3. Ті самі дані → узгоджено ВСЕ: більше → гучніше, вище регістр, густіше, яскравіший тембр, напруженіша
   гармонія (не лише гучність). Помірно і гармонійно: межі гучності ~12 дБ, без «крику».
Тести (field-tests): ISS 5011 — гучність корелює з часткою жовтих точок на диску (ρ ≥ 0.7); фаза наближення з
кількома точками тихіша за фазу «планета вся в точках». CO₂ 5196 — гучність і висота корелюють із centerValue
(ρ ≥ 0.7); з позицією у треку — |ρ| < 0.3. Perpetual Ocean 5425 — кореляція гучності з площею диска на екрані
|ρ| < 0.3.

## Блок B — «точкові» дані звучать як нічні вогні з галереї
Визнач тип даних «точки» (багато дрібних яскравих плям на темному/однорідному тлі: блискавки, хмара точок CO₂,
осередки вогню, вогні міст). Для них — той самий підхід, що сподобався в нічних вогнях галереї: кожна
точка/кластер → коротка дзвінка нота (тембр — від теми: блискавки — сухий удар + дзвін, CO₂ — м'які дерев'яні/
скло, вогонь — тріск + маримба), густота нот = кількість точок на видимій поверхні, панорама = положення
точки (схід/захід), висота — за значенням/яскравістю точки, нова точка → нова нота (для блискавок — коротка
«подія»). Під цим — тихий теплий пед і м'який пульс. Тест: ρ(нот на такт, к-сть точок на диску) ≥ 0.8 для
ISS і CO₂.

## Блок C — пожежа: два різні голоси
Для теми fires (і картки 4993): розділити класи кольорів: «горить зараз» (жовтий/помаранчевий/червоний,
насичені) і «згоріло» (сіре, ненасичене). Горить → тривога: ритм, ударні, напруга, тріск, ерікон на нових
осередках. Згоріло → накопичення: низький бас/дрон, висота й гучність якого монотонно росте з часткою згорілого
(«рахунок втрат»). Озвучення/опис: «Звучать два голоси: вогонь, що горить, і площа, що вже згоріла».
Тест: дрон «згоріло» монотонно неспадний (ρ із часткою сірого ≥ 0.9); ударні корелюють з часткою активного
вогню (ρ ≥ 0.7).

## Блок D — різноманітність (не «скрізь та сама база»)
1. Мотив голосу даних для завантаженого відео — власний: «мелодійний відбиток» карти (профіль головного
   значення вздовж довготи/ширини перших кадрів → 5–8 нот у ладі теми) + seed від файлу; два різні відео
   однієї теми мають різні мотиви.
2. Розширити бібліотеку для тем без власного звуку: для кожної з 14 тем — свої мотивні шаблони (ритм, інтервали),
   свій малюнок ударних і свій пед/текстура; generic — лише якщо тему не визначено.
3. Акомпанемент не однаковий: щонайменше 4 різні фактури (пульс, арпеджіо, хоральні акорди, остинато) за темою
   й даними.
Тест: на 7 відео field-tests + 5 галереї — мотиви попарно різні (відстань ≥ 3 ноти), ≥ 4 різні фактури,
≥ 5 різних інструментів голосу.
