## Блок C — шкала без легенди + перемикач полярності (тег `safe-10c`)
- `src/analysis/palette.js`: якщо colorbar у кадрі немає і шкала не «синій → червоний», кольори даних упорядковуються вздовж головної осі в Lab (PCA) → 32 опорні кольори «менше → більше» (світліше = більше; для осі відтінку — тепліше). Двигун читає їх тим самим `scaleValue`, що й знайдену шкалу; працює лише для завантажених файлів (`autoPalette`).
- UI: «Більше значення — це: автоматично / світліше / темніше / тепліше» з озвученням; вибір і тема зберігаються для файлу (localStorage). Синоніми «висота лісу», «canopy height» → тема vegetation.
- test.html: 145/145. Зелена шкала й viridis: paletteValue монотонний (ρ = 1.00); «темніше» дзеркалить голос даних (ρ значень = −1.00).

- «Важке» відео (> 150 МБ або ширше за 2560 px): аналіз ≤ 400 кадрів, один декодер; файл > 40 МБ не читається в пам'ять як data-URL; `openVideo(url, { direct: true })` — без завантаження в blob.
