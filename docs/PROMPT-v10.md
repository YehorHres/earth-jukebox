## ЧЕРГА (за пріоритетом)

### 1. Гучність = кількість даних, а не площа на екрані  [скарги: блискавки, CO₂, океан]
Скарги: ISS — на початку (планета наближається, 3 точки) дуже голосно, коли планета вся в жовтих точках —
тихіше; CO₂ — Африка (менше CO₂) голосніша за Південну Америку (більше); Perpetual Ocean — наближення до білої
затоки на весь екран — голосно, вся планета — тихо.
- «Кількість» = частка даних на ВИДИМІЙ поверхні (піксели даних / піксели диска або карти в кадрі).
- Рух камери, наближення, обертання, площа диска й позиція в треку НЕ впливають на гучність/напругу/кульмінацію.
  Форма треку (вступ/наростання/кульмінація/розв'язка) для завантажених відео — тільки з ряду «кількості»;
  вступ ≤ 2 такти.
- Більше даних → узгоджено: гучніше + вище регістр + густіше + яскравіший тембр + напруженіша гармонія.
Тести: ISS — ρ(гучність, частка точок на диску) ≥ 0.7, фаза «3 точки» тихіша за «вся в точках»; CO₂ —
ρ(гучність і висота, centerValue) ≥ 0.7, |ρ(гучність, позиція в треку)| < 0.3; Ocean — |ρ(гучність, площа диска)| < 0.3.

### 2. Точкові дані — принцип нічних вогнів, але свій характер
Принцип: кожна точка/кластер → звук на своєму місці (панорама = положення), густота = кількість точок,
нова точка → новий звук. Звучання — своє:
- блискавки: ДРАМАТИЧНО — різкий яскравий тріск/удар + із затримкою далекий низький гуркіт грому; напруга росте
  з кількістю спалахів; окремі спалахи — події (зараз 0 подій — виправити);
- вогонь: КРАСИВО й тепло — потріскування, жар (теплі педи), іскри вгору; більше вогню — тривожніший ритм;
- CO₂ (хмара точок): м'які щільні «хмари» звуку, що густішають, «задуха» (звуження стерео, закриття фільтра).
Тест: ρ(звуків на такт, к-сть точок на видимій поверхні) ≥ 0.8 для ISS і CO₂.

### 3. Пожежа — два голоси  [скарга: «що міряємо — згоріле чи те, що горить?»]
«Горить зараз» (насичені жовтий/помаранчевий/червоний) → тривога: ритм, ударні, тріск, напруга, звук-знак
на нових осередках. «Вже згоріло» (сіре) → низький бас/дрон, що монотонно наростає («рахунок втрат»).
Опис: «Звучать два голоси: вогонь, що горить, і площа, що вже згоріла».
Тести: дрон «згоріло» — ρ із часткою сірого ≥ 0.9 і неспадний; ударні — ρ з активним вогнем ≥ 0.7.

### 4. Унікальність  [скарга: «скрізь та сама база й та сама мелодія»]
- Мотив голосу даних кожного відео — власний: «відбиток» карти (профіль головного значення вздовж карти перших
  кадрів → 5–8 нот) + seed від файлу.
- ФОН/база теж своя: щонайменше 4 різні фактури (пульс, арпеджіо, хоральні акорди, остинато, текстури природи),
  свій малюнок ударних (або тиша), свій пед — за темою й даними.
- Характер кожної теми = відчуття явища: вогонь — тріск і тривога; блискавки — сухі удари й грім; CO₂ — щільність
  і задуха; океан — плавні хвилі, легато; ліс — дерев'яні духові, простір, повітря; нічні вогні — як є.
Тест (7 field + 5 галереї): мотиви попарно різні (≥ 3 ноти), ≥ 4 фактури, ≥ 5 інструментів голосу, різні BPM.

### 5. «Де більше» — для незрячих
- Панорама кожного голосу/точки = горизонтальне положення (захід — ліве вухо, схід — праве);
  найактивніша зона — окремий солюючий голос.
- Словами (у вступі, на W і в підсумку): «найбільше горить на сході», «найбільше CO₂ над Південною Америкою»
  (плоска карта — регіони за широтою/довготою; глобус — частина диска; з карткою EIC — назви регіонів з картки).
Тест: ρ(панорама соліста, позиція максимуму) ≥ 0.8.

### 6. Галерея
(а) прибрати з інтерфейсу тестові пункти («Тест: темна нічна карта…», «Тест: статичне відео…») — у test.html лишаються.
(б) ПІСЛЯ блоків 1–5 додати відео з field-tests, що звучать добре за звітом (мінімум GEDI 4950, ISS 5011, Dixie 4993,
CO₂ 5196; бажано 5313, 5425, 5533): копії H.264 MP4 + WebM, ≤ 1080p, ≤ 40 МБ кожна (ліміт GitHub 100 МБ),
обрізані до найінформативніших 60–90 с (ffmpeg / npx ffmpeg-static / pip imageio-ffmpeg без глобальної установки);
постер; готовий *.analysis.json; картка з catalog.json (uk + en, кредит «NASA SVS <id>»); власний золотий відбиток.
Оригінали field-tests не комітити.

### 7. Голос пояснює + швидкість мовлення
- Вступ ≤ 20 с для відео з карткою або темою: що це, звідки дані, роки, як слухати («кожна точка — блискавка,
  звучить тріском; ліве вухо — захід…»), потім 1 с тон-орієнтир.
- Клавіша W «Що зараз?»: час/дата, де найбільше, росте чи падає, наскільки (з одиницями, якщо є шкала/картка).
- Підсумок після треку: тренд, максимум (коли й де), кількість подій. Також текстом на сторінці.
- Швидкість мовлення для ВСЬОГО озвучення (під курсором, вступ, W, підсумок): повзунок 0.5×–2× (крок 0.25,
  за замовчуванням 1×) у панелі «Доступність» + клавіші; фраза-приклад після зміни; localStorage; uk + en.
- Під час мовлення музика приглушується; усе вимикається.

### 8. Таймлайн + швидкість відтворення + мікшер
- Таймлайн: шкала часу з підписами (0:00, 0:30… або роки з картки, напр. 2017…2023); повзунок ПЕРЕТЯГУЄТЬСЯ
  мишею/пальцем, не лише клік; позначки розділів і подій (з підказкою при наведенні); ←/→ ±5 с, Home/End;
  role="slider", aria-valuetext («1:20 з 2:40, кульмінація»).
- Швидкість відтворення 0.5×/0.75×/1×/1.25×/1.5× + клавіші [ ]: відео й музика синхронно (< 50 мс), висота
  нот не змінюється.
- Мікшер: повзунок гучності кожної партії + «Голос даних» + загальна гучність (+ наявні Вимк./Соло);
  aria-valuetext; localStorage; партитуру не змінює (золотий тест зелений).

### 9. Карти змін (розбіжні шкали)
Два кольори навколо нейтрального (5313: фіолетове — світла більше, помаранчеве — менше): знак зміни → росте:
вгору й мажор; падає: вниз і мінор; нейтральне — тиша/пед.

### 10. Менше хаосу
Не більше ~1 події на 2–3 с, лише найсильніші (AirQuality мав 90).

### 11. (якщо лишився час) Режим «Тільки дані» і клавіші навігації
Перемикач «Музика / Тільки дані» (голос даних + звуки-знаки без супроводу — для журі: чистий зв'язок звуку з
даними); клавіші N/P — наступна/попередня подія, ? — список клавіш (озвучується).
